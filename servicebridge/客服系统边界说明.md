# 客服系统边界

## 产品边界

ServiceBridge 服务网站访客在线咨询。访客使用官网右下角入口或访客独立页；人工客服使用 Flutter「在线客服」App；管理员使用 `1337` 统一控制台（Arco Design Pro Vue）。官网内容管理负责客服入口文案和地址，客服管理、会话工作台、推送配置与系统设置同属统一控制台的独立栏目。

## 已实现（本轮已补齐）

- 访客会话、消息、上传、历史分页、评价和 WebSocket 实时通信；访客可一键转人工。
- AI 自动回复（携带会话上下文、按会话语言）、关键词快捷回复、转人工状态、无回复回退；AI 超时按后台配置生效。
- 营业时间：非营业时间 AI 继续接待，但不自动分配人工，并给访客发送可配置留言。
- 客服 App 登录、状态、会话队列、未读、历史分页、文字/图片/**语音播放**、**撤回**、**访客备注**、关闭、改密、头像、重连退避与登录态失效回登录。
- 推送：参数在控制台配置并加密入库；FCM 服务账号自动换令牌、APNs `.p8` 签名、按平台路由；新会话分配/转接/访客新消息都会触发；`GET /api/app-config` 向 App 下发公开 Firebase 参数。
- 访客端显示真实接待客服姓名与头像（`assigned_agent_name` / `assigned_agent_avatar`），阿拉伯语 RTL。
- 统一控制台：客服账号、数据概览、会话查看/转接/结束/导出、关键词、服务评价、审计日志、App 版本、API 管理和系统设置（营业时间/联系方式/AI/推送）。
- 第三方开放接口（Open API）与 API Key 管理：会话按应用隔离、令牌桶限速、只读 WebSocket 订阅。
- PostgreSQL 持久化、Redis 跨节点事件、对象存储、限流、审计与 `/metrics`；内存仓库与 PostgreSQL 行为一致。
- 运维：Caddy 直接终止 TLS、Prometheus/Grafana（`monitoring` profile）、备份与隔离库恢复脚本、`scripts/verify-all.sh` 一键验证。

## 仍需外部条件

- 生产推送凭证（Firebase 服务账号、APNs `.p8`）与真机后台/锁屏/进程回收验证。
- Android/iOS 正式签名、商店素材、隐私清单与发布流程。
- 真实内容素材（产品图/视频/参数/下载资料/法务文本/联系方式）由管理员从控制台上传。
- 生产域名/DNS/证书上线、容量阶梯压测、备份恢复演练与告警通道接入。
- 浏览器与真机端到端自动化需要在具备 Chrome 与 `.env` 的环境执行。

## 安全边界

- 访客 token 只能访问绑定会话；客服只能操作自己负责的会话；管理员可以管理全部会话。
- WebSocket 必须校验来源，生产 `CORS_ALLOWED_ORIGINS` 禁止使用 `*`。
- 只有 `TRUSTED_PROXY_CIDRS` 中的代理头可作为真实访客 IP。
- 管理和客服改密、重置、禁用后必须撤销旧 token 并断开在线连接。
- 统一控制台在服务端代理客服管理员请求，不向浏览器暴露客服引擎管理员密码。
- 控制台静态资源路由做目录包含校验，拒绝 `..`/编码绕过读取任意文件。
- 推送密钥、AI Key、S3 凭据使用主密钥 AES-256-GCM 加密入库，接口只返回掩码。
- 生产凭证只能来自环境变量或密钥系统，不能写入代码、Markdown 或 Git 数据文件。

## 验收边界

「本地核心闭环完成」表示访客发起咨询、管理员创建客服、App 在线登录和接待已经验证；「商业上线」还要求推送真机、正式签名、自动化端到端、可观测性、备份恢复和容量验收通过。两者不能混为同一完成状态。
