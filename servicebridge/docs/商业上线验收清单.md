# ServiceBridge 商业上线验收

只有以下项目全部完成，才可标记为商业上线。

## 产品闭环

- [ ] 官网所有主要页面展示客服入口，点击加载正确的客服域名。
- [ ] 访客可创建/恢复会话，发送文本、图片和语音，刷新后历史一致。
- [ ] 客服 App 可登录、上线、接待、回复、备注、转接、撤回、关闭，并在后台收到系统推送。
- [ ] 统一后台可管理客服、会话、AI、关键词、营业时间、联系方式、评价和审计。
- [ ] 访客与客服双浏览器实时收发、断线重连、重复发送幂等通过。
- [ ] 空状态、加载状态、错误状态、权限失效和移动端布局通过。

## 代码门禁

- [ ] `go test ./...`、`go vet ./...` 通过。
- [ ] 官网生产构建通过，无 TypeScript/Astro 错误。
- [ ] Compose 配置、Shell 语法、冒烟和端到端测试通过。
- [ ] 仓库无已删除集成、旧后台、弱口令和真实密钥残留。
- [ ] API 文档、环境模板和任务清单与当前代码一致。

## 生产资源

- [ ] PostgreSQL、Redis、对象存储、DNS、TLS、备份和监控已准备。
- [ ] 数据库与上传文件完成恢复演练，记录 RPO/RTO。
- [ ] 日志集中采集，健康、错误率、延迟、磁盘和连接数有告警。
- [ ] `CORS_ALLOWED_ORIGINS`、`FRAME_ANCESTORS`、可信代理和上传公开地址正确。
- [ ] 所有默认密码、示例域名和占位密钥均已替换。

## 容量与故障

- [ ] 阶梯压测到目标并发，连接成功率和 ACK P95 达到业务指标。
- [ ] 单后端实例下线后，已有/新会话行为符合预期。
- [ ] Redis 短暂不可用、PostgreSQL 不可用和对象存储失败都有可识别错误与告警。
- [ ] 发布、数据库迁移、应用回滚和证书续期完成演练。

当前仓库已经具备客服 App 和统一后台的核心闭环，但推送、完整运营界面、自动化端到端和生产资源验收尚未全部通过，因此仍不能判定为商业上线。剩余项见仓库根目录 `功能完善任务.md`。
