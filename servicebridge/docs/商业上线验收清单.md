# ServiceBridge 商业上线验收

只有以下项目全部完成，才可标记为商业上线。`[x]` 表示本轮已通过代码/自动化验证；`[ ]` 表示仍需生产环境或人工执行。

## 产品闭环

- [x] 官网所有主要页面展示客服入口，点击加载正确的客服域名。
- [x] 访客可创建/恢复会话，发送文本、图片和语音，刷新后历史一致；可一键转人工，已结束会话保留历史与评价入口。
- [x] 客服 App 可登录、上线、接待、回复、备注、撤回、播放访客语音、关闭，并接收推送（含新会话与转接）。
- [x] 统一控制台可管理客服、会话、AI、关键词、营业时间、联系方式、服务评价、审计、App 版本、API 授权与推送配置。
- [x] 访客与客服实时收发、断线重连（指数退避）、重复发送幂等、登录态失效回登录。
- [x] 空状态、加载状态、错误状态、权限失效和移动端布局；阿拉伯语 RTL。
- [ ] 生产推送真机验证：锁屏、后台、进程被回收三种状态收到通知，点击直达会话。

## 代码门禁

- [x] `go test ./...`、`go vet ./...` 通过。
- [x] 官网生产构建通过（中文 + `/en` + `/ar`，缺译文时跳过而不失败），无 TypeScript/Astro 错误。

- [x] API 文档、环境模板和任务清单与当前代码一致。

## 生产资源

- [ ] PostgreSQL、Redis、对象存储、DNS、TLS、备份和监控已在生产就绪（Compose 与脚本已具备，需在目标服务器执行）。
- [ ] 数据库与上传文件完成恢复演练，记录 RPO/RTO（脚本 `scripts/restore-production.sh` 与流程文档已具备）。
- [ ] 日志集中采集，健康、错误率、延迟、磁盘和连接数有告警（Prometheus 规则与 Grafana 仪表盘已具备，需接入告警通道）。

- [ ] 所有默认密码、示例域名和占位密钥均已替换为生产值。
- [ ] 真实内容素材（产品图/视频/参数/下载资料/法务文本/联系方式）已在控制台配置完成。

## 容量与故障

- [ ] 阶梯压测到目标并发，连接成功率和 ACK P95 达到业务指标（步骤与记录模板见 `servicebridge/scripts/loadtest/README.md`）。
- [ ] 单后端实例下线后，已有/新会话行为符合预期。
- [ ] Redis 短暂不可用、PostgreSQL 不可用和对象存储失败都有可识别错误与告警。
- [ ] 发布、数据库迁移、应用回滚和证书续期完成演练。
- [ ] Android/iOS 正式签名与商店发布完成（`aps-environment` 改为 `production`）。
