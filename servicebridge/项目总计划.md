# ServiceBridge 项目计划

## 目标

建设一套不依赖外部接待平台的网站在线客服：访客在官网发起咨询，客服在自有移动 App 处理，管理员通过统一控制台（Arco Design Pro Vue）完成账号、会话、AI、推送、内容和运营配置。

## 当前状态

- 后端领域逻辑、HTTP API、WebSocket、内存/PostgreSQL 仓库、Redis 广播、FCM/APNs 推送通道均已具备。
- 访客用户端已接入真实 API 并可嵌入官网，支持文本/图片/语音、历史分页、评价、转人工与 RTL。
- 统一控制台已整体迁移到 Arco Design Pro Vue，客服、运营、内容、翻译、素材、系统设置与推送均为原生页面。
- Flutter 客服 App 核心接待闭环完成，并通过 Android 真机联调；推送配置改为服务端下发。
- 部署、监控 profile、备份/恢复脚本与一键验证已具备。

当前最大缺口是**生产凭据与真机验收**：推送真机验证、正式签名与商店发布、真实内容素材、生产上线与容量/恢复演练。

## 交付阶段

### 阶段一：可接待闭环（已完成）

- App 登录、在线状态、会话列表、历史分页、文本/图片/语音、未读、重连、撤回、备注和关闭。
- 统一控制台客服账号、会话查看、转接、关闭、导出和配置管理。
- 访客端文本/图片/语音、评价、转人工与会话恢复。

### 阶段二：管理和运营（已完成）

- 数据概览、会话监控、客服账号、AI（含缓存探测与测试回复）、营业时间、联系方式、关键词、服务评价、审计日志、App 版本、API 管理与推送设置。
- 内容闭环：官网内容编辑器、草稿预览、降级版本、网站翻译与 R2 素材库。

### 阶段三：生产上线（部分完成）

- 已完成：Caddy 直连 TLS、Compose（含 `monitoring` profile）、Prometheus 告警规则、备份与隔离库恢复脚本、`scripts/verify-all.sh`、容量压测步骤文档。
- 待完成：生产推送凭据与真机验证、正式签名发布、域名上线、容量阶梯压测、恢复演练、告警通道接入与浏览器/真机端到端自动化。

执行级任务以仓库根目录 `功能完善任务.md` 为唯一清单，本文件只描述阶段目标。
