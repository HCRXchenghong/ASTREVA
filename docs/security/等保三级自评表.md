## 四、安全计算环境（核心）

| 控制点 | 现状 | 证据/待办 |
|---|---|---|
| 身份鉴别-口令复杂度与定期更换 | 部分实现 | 客服口令有强度校验（Go `validatePassword`）；**管理员口令策略建议加复杂度与 90 天轮换**（当前初始化/改密强制 ≥12 位） |
| 身份鉴别-双因素 | 已实现 | 管理员 TOTP；`admin-server/modules/auth-router.mjs` |
| 身份鉴别-登录失败处理 | 已实现 | 15 分钟 10 次失败锁定（429 + Retry-After），2FA 单挑战 5 次上限，TOTP 防重放；初始化接口独立限速；集成测试 `security-hardening.integration.test.mjs` |
| 身份鉴别-远程管理防窃听 | 已实现 | 全站 HTTPS + HSTS |
| 访问控制-最小权限 | 已实现 | 客服仅能操作自己负责会话（越权 403 有测试）；只读围观默认限本人/本组/未分配会话，接管/转接/结束/停用即清理；开放 API 默认关闭，后台安全策略可开关 |
| 访问控制-默认账户与口令 | 已实现 | 生产环境 `APP_ENV=production` 下示例密钥/口令拒绝启动；首启必须提交一次性 `ADMIN_SETUP_TOKEN` 并绑定 2FA；已有管理员时旧初始化挑战被拒绝 |
| 安全审计-覆盖与留存 | 已实现 | 系统日志（控制台+官网访问+客服引擎审计）；安全事件 ≥180 天、访问明细 30 天，每日自动清理；CSV 导出 |
| 安全审计-审计记录保护 | 已实现 | 审计表仅按保留策略清理，且安全事件清理硬下限 180 天；`site_audit_events` + `site_system_events` |
| 入侵防范-漏洞利用防护 | 已实现 | 参数化 SQL、HTML 白名单消毒、路径穿越防护（含编码绕过）、上传魔数校验、SSRF 出站白名单 |
| 入侵防范-资源控制 | 已实现 | 公开接口 IP 限流、访客建会话限速、上传大小+每日配额、WebSocket 连接上限/生命周期、AI 超时与最大 token、HTTP 超时 |
| 数据完整性 | 已实现 | 内容修订号乐观锁（409）；备份脚本 SHA-256 逐字节校验 |
| 数据保密性 | 已实现 | AES-256-GCM 加密密钥字段；bcrypt 口令；API Key SHA-256 |
| 数据备份恢复 | 已实现（脚本级） | `scripts/backup-production.sh`（PostgreSQL + 本地媒体卷）、`scripts/restore-production.sh`（隔离库恢复 + 计数校验）；**完整媒体恢复演练记录需你侧补** |
| 剩余信息保护 | 部分实现 | 会话可撤销；退出即清 Cookie；**建议：DB 字段级加密扩展、日志脱敏策略评审** |
| 个人信息保护 | 已实现（设计层） | 画像可关闭；IP 属个人信息随访问日志过期；Cookie 同意分四类；未同意时只发送不含本地标识的匿名 PV，服务端仍按安全审计需要保留 IP/UA 30 天 |
| 恶意代码防范（主机） | 需你侧完成 | 镜像扫描、主机 EDR |

## 七、结论与差距清单（按优先级）

1. **必须由你侧推进**：定级备案 → 选择有资质测评机构 → 测评与整改 → 监督检查。
2. **建议尽快补齐的代码/配置项**：
   - 管理员口令复杂度与 90 天轮换策略；
   - 审计员只读角色（当前仅管理员/客服两类）；
   - 主机与镜像漏洞扫描、EDR（基础设施层）；
   - WAF/云防火墙（边界层，应用层已有危险检测与限流）；
   - 备份恢复**演练记录**与应急预案文档。
3. **已达标的技术项**：身份鉴别（含 2FA/锁定/防重放）、访问控制（最小权限 + 会话撤销 + 来源校验）、安全审计（分层留存 + 危险识别）、数据保密完整（加密 + 乐观锁 + 消毒）、应用层入侵防范与资源控制、应用层备份校验。
