# ASTREVA 安全设计说明书

> 版本：v1.4.5 · 更新时间：2026-11-10

> 适用系统：官网（静态站）+ 统一控制台（Arco SPA）+ 官网后台服务（admin-server）+ 客服引擎（ServiceBridge Go）+ 客服 App（Flutter）+ 访客聊天端。
> 版本：二期（含系统日志、会话可撤销、翻译与画像）。本说明书用于等保测评与技术交付。

## 1. 系统边界与信任域

| 域 | 组件 | 暴露面 |
|---|---|---|
| 公网官网 | Astro 静态站（nginx） | 仅静态文件 + 表单 POST + 访问埋点 |
| 公网后台 | admin-server（Node ESM） | `/site-admin/*`（2FA 会话）、`/site-admin-api/*`（会话 + 来源校验）、公开只读接口 |
| 公网客服 | 客服引擎（Go） | `/api/*`（客服/管理员令牌）、`/uploads/*`（静态）；`/open/v1/*` 默认关闭，由后台安全策略开关控制 |
| 访客端 | 客服挂件（user-web） | 无服务端状态，全部经客服引擎 |
| 内网 | PostgreSQL、可选 S3、构建服务 Webhook、Prometheus/Grafana | 仅容器网络或 127.0.0.1 |
| 边缘 | Caddy（80/443、自动 TLS、HSTS） | 唯一入口，反向代理各服务 |

信任边界：①浏览器 ↔ Caddy；②Caddy ↔ 各服务；③服务 ↔ PostgreSQL/对象存储；④服务 ↔ AI/推送等第三方上游。

## 2. 身份鉴别

- **管理员**：邮箱 + 密码（bcrypt）+ **TOTP 双因素**；首次初始化必须提交 `ADMIN_SETUP_TOKEN`（生产环境必须显式配置；一键脚本生成并只在终端打印一次），且服务端会再次确认“仍无管理员”，防止初始化窗口被抢占或旧挑战覆盖已建账号。会话 Cookie 带 `sid` 并在服务端校验；登出、重置密码/2FA、删除账号都会撤销会话。
- **客服**：账号 + 密码（bcrypt，口令复杂度校验），登录颁发令牌；改密后断开其全部实时连接。
- **访客**：匿名会话令牌（仅能访问自己的会话）。
- **开放 API**：后台「安全策略」总开关，默认关闭；关闭时 `/open/v1/*` 返回 503，开启后仍需 API Key + scope。
- **防护**：登录失败按 IP+账号计数（默认 15 分钟 10 次锁定）；2FA 单挑战最多 5 次尝试；TOTP 验证码在 ±1 时间窗内**不可重放**；`APP_ENV=production` 下示例密钥/弱密钥直接拒绝启动（admin-server 与 Go 均校验）。

## 3. 访问控制

- 控制台按会话鉴权；`/site-admin-api/*` 状态变更接口同时校验 **Origin** 与 **CSRF 双提交令牌**（`X-CSRF-Token` + 同值 Cookie + 会话内 `csrf`）。后台写接口只接受同源（或显式 `ADMIN_WRITE_ALLOWED_ORIGINS`），不再把官网读/提交白名单当作后台写白名单；会话 Cookie 为 `SameSite=Strict`。
- 客服引擎管理接口按账号类型鉴权（管理员/客服），客服只能操作自己负责的会话（越权返回 403，有集成测试）。只读围观是受控产品功能：默认只允许围观未分配、本人负责或本组队列中的未结束会话（后台“安全策略”把围观范围改为 `all` 才恢复任意客服围观）；会话被接管/转接/结束/删除或客服停用后会立即清理围观权限。
- 开放 API 默认关闭；后台开启后按 Key 归属隔离并逐接口校验 scope。
- 对象存储直传使用预签名 URL，有效期短、按素材 ID 限定路径。
- 访客聊天页仅允许被官网域名 iframe（`frame-ancestors`），访客会话 token 只发给白名单父 Origin，不再使用 `'*'`。
- 草稿预览使用每次构建随机 token 的路径（`/__preview/<token>/`），Caddy `forward_auth` 向 admin-server 同时校验构建 token 与 HttpOnly 预览 Cookie（默认 10 分钟，可在后台「安全策略」调整为 5–120 分钟；由后台登录会话领取）后才代理静态文件，并设置 `X-Robots-Tag: noindex`；预览内容同样经过富文本/链接消毒。

## 4. 数据保密性与完整性

| 数据 | 保护 |
|---|---|
| 管理员/客服口令 | bcrypt 哈希，不可逆 |
| AI Key、S3 密钥、推送凭证 | AES-256-GCM 加密入库（`CMS_DATA_ENCRYPTION_KEY`）；后台常规接口只回掩码。供应商明文配置仅允许服务间通过 `INTERNAL_API_TOKEN` 读取，浏览器代理显式拒绝 `/secret`、`/resolve`。 |
| 传输 | 全站 HTTPS（Caddy 自动证书）+ HSTS |
| 内容完整性 | CMS 保存带修订号（乐观锁，冲突 409）；日志与审计只追加 |
| 富文本 | 写入前 HTML 白名单消毒（含未闭合标签、`javascript:`/`//host` 链接）；翻译 AI 输出与草稿预览同样消毒；JSON-LD 使用 script 上下文安全序列化；公网站点启用严格 CSP/XFO（脚本/样式不用 `unsafe-inline`）作为纵深防御 |

## 5. 安全审计（本期新增）

- **系统日志**（控制台 `系统日志` 页）：控制台事件 + 官网访问明细（IP、UA、浏览器、系统、设备、国家、来源页）+ 客服引擎审计事件，统一中文展示，支持等级/分类/IP/关键词/时间筛选与详情弹窗。
- **危险识别**：目录穿越、`.env`/`.git`/`wp-admin` 等敏感路径探测、SQLi/XSS 特征、扫描器特征、登录爆破、2FA 爆破、失效 Key、限流触发、非白名单来源。
- **留存**：安全事件与管理员操作 ≥180 天（清理接口硬下限 180 天，无法通过参数降到 30 天），访问明细 30 天（分层保留，每日自动清理），支持 CSV 导出与手工清理。
- **时间**：所有时间戳 UTC 入库，展示按站点时区。

## 6. 入侵防范与资源控制

- 输入校验：路径穿越防护（含 URL 编码绕过）、上传 MIME 魔数校验、SVG/HTML 禁入、文件大小与**每访客每日上传配额**；访客上传禁止 APK。
- 限流：公开接口按 IP 限流、访客建会话单独限速、WebSocket 全局/单账号连接上限与最大生命周期、登录失败锁定。
- 出站白名单：AI 生图/翻译等上游主机白名单（防 SSRF）；Bark 等自定义提醒地址在生产环境禁止私网/回环/链路本地并禁用重定向；对象存储与 AI 地址仅管理员可改并写审计。
- 容器：admin-server、Go 客服引擎、rebuild-webhook 均以非 root 运行；健康检查、日志轮转；HTTP 服务设置读/写/空闲超时。

## 7. 备份与恢复

- PostgreSQL 逻辑备份 + 本地媒体卷（`admin-uploads`、`servicebridge-uploads`）tar.gz 备份，均生成 SHA-256 并逐字节校验；对象存储模式按桶版本/复制管理。备份/恢复脚本使用 `ASTREVA_STACK_NAME` 固定 Compose 项目。
- 恢复脚本支持恢复到隔离库并校验内容/用户/线索/审计条数一致。
- 建议：每日增量 + 每周全量，异地保留 ≥30 天，每季度演练一次。

## 8. 剩余风险与处置

| 风险 | 处置 |
|---|---|
| 管理员账号被盗 | 2FA + 会话可撤销 + 登录锁定 + CSRF 双提交 + 危险日志告警 |
| AI 上游泄露对话 | 只发送必要上下文；密钥加密；可在后台随时更换上游 |
| 翻译/画像涉及个人信息 | 画像可关闭；IP 属个人信息，随访问日志保留策略过期；提供隐私政策与同意管理 |
| 第三方 IP 库 | 仅管理员配置，记录出站域名与调用量 |
