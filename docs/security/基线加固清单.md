# 基线加固清单（主机 / 容器 / 数据库 / 应用）

> 每条给出可执行步骤与验证方法。`[已实现]` 表示仓库里已有代码或配置，`[待执行]` 表示需要在服务器上操作。

## 1. 主机（Ubuntu 22.04/24.04）

```bash
# 1.1 只保留必要端口 [待执行]
sudo ufw default deny incoming && sudo ufw allow 22/tcp && sudo ufw allow 80/tcp && sudo ufw allow 443/tcp && sudo ufw enable

# 1.2 SSH 加固 [待执行]
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin no/;s/^#\?PasswordAuthentication.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo systemctl restart ssh

# 1.3 自动安全更新 [待执行]
sudo apt install -y unattended-upgrades && sudo dpkg-reconfigure -plow unattended-upgrades

# 1.4 时间同步（审计时间可信）[待执行]
timedatectl set-ntp true && timedatectl status

# 1.5 日志留存（≥180 天，配合应用日志）[待执行]
sudo sed -i 's/^#\?SystemMaxUse=.*/SystemMaxUse=2G/' /etc/systemd/journald.conf && sudo systemctl restart systemd-journald
```

## 6. 上线前检查清单

1. `APP_ENV=production`，`ADMIN_2FA_SESSION_SECRET`、`CMS_DATA_ENCRYPTION_KEY`、`INTERNAL_API_TOKEN` 使用 32 位以上随机值（应用会强校验）；首次初始化前从日志获取 `ADMIN_SETUP_TOKEN`。
2. `PUBLIC_SITE_URL` 改为真实域名（否则 canonical/sitemap 全错，SEO 失效）。
3. 数据库、对象存储使用强口令且不对外发布端口。
4. Caddy 证书签发成功、HSTS 生效、`/healthz` 与监控告警可用。
5. 执行一次 `scripts/verify-all.sh`（全绿）与一次备份→隔离恢复演练并留存记录。
6. 控制台创建管理员并绑定 2FA；删除/禁用所有临时账号；确认「系统日志」无异常高危项。
