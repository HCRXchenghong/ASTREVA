## 一、已实现（均有测试或真实环境验证）

### ① 工作台的官网数据与健康度
- 今日 PV/UV/询盘/发起会话、本月 PV/UV 曲线（自绘 SVG，无新增依赖）。
- 服务器资源：CPU 使用率+负载+核数、内存（系统/进程/cgroup）、磁盘（按挂载点）、数据库（大小/连接数/上限）。
- 服务健康：控制台、客服引擎、构建服务、对象存储、AI 生图、网站翻译（状态色 + 延迟 + 失败原因）。
- 数据来源：**第一方埋点**（`POST /site-admin-api/analytics/visit`，来源白名单 + 限流 + 爬虫过滤）。
  - **页面浏览始终采集**：已同意 analytics 时带 `visitor_id/session_id`；未同意时只发 `anonymous:true`（前端不写任何本地标识）。
  - **匿名 UV 口径**：服务端用「当日轮换的盐 + 归并 IP（IPv4 /24、IPv6 /64）」派生 `anon_<16 字节 HMAC>` 作为 `visitor_id`，UV 仍是 `COUNT(DISTINCT visitor_id)`，因此未同意访客也计入 UV；但匿名键**只在当天去重、无法跨天识别同一人**（最小化原则）。
  - **访问明细（含 IP/UA）照常入库**，用于系统日志、危险识别与安全审计；`anonymous` 标记随明细一起保存，便于区分两种口径。
  - **同意迟到不补发**：加载时已按匿名口径发出 pageview 的，之后点同意不会补发带标识的同页 pageview（避免同一次浏览计两次 PV）；静态站每次导航都是新的页面加载，下一次浏览即带标识。

### ② 系统日志
- 合并三类来源：控制台事件 + 官网访问明细（IP/UA/浏览器/系统/设备/国家/来源页）+ 客服引擎审计。
- 中文展示、等级（info/warning/danger）、分类筛选、关键词与 IP 搜索、详情弹窗（含 UA 全文与明细 JSON）、危险行高亮、CSV 导出、按 IP 过滤。
- **危险识别**：目录穿越、敏感路径探测（.env/.git/wp-admin/phpmyadmin…）、SQLi/XSS 特征、扫描器特征、登录爆破、2FA 爆破、非白名单来源写请求。
- **分层保留**：安全事件与管理员操作默认 **180 天**、访问明细 **30 天**（可配 30–3650 / 1–365，每日自动清理，清理动作写审计）。

### ③ 导航重排
- 6 个根：工作台（数据看板）→ 运营中心（询盘管理/咨询单/客服账号/服务评价/关键词规则/**客服策略**/**排队队列**/**黑名单**/**访客画像**）→ 内容管理 → AI 管理（接待 AI/生图/SEO/翻译 AI/**模型供应商**/**能力绑定**/**知识库**/**限额**）→ 应用管理（App 版本/API 管理）→ 系统（系统日志/审计日志/营业时间与联系方式/推送设置/安全策略式设置/**提醒设置**）。
- 旧地址全部 302/重定向到新路由，旧后台页面已下线。

### ④ AI 统一配置 + 知识库 + 限额
- **多供应商**：可建任意多组 URL+Key，每组可不同模型；**一键获取模型**后模型框变下拉可任选；连通性测试给延迟与模型数；出站主机白名单防 SSRF；密钥 AES-256-GCM 加密、只回掩码。
- **能力绑定**：接待 AI / 翻译 / 语言检测 / AI SEO / AI 生图 各绑一个供应商+模型；未绑定自动回退"系统设置"里的原有上游（升级零影响）。admin-server 侧的**网站翻译、AI SEO、AI 生图也已接入同一套供应商**（60 秒 TTL，保存即失效）。
- **知识库（多库）**：条目 CRUD + 批量导入 + **检索预览**（分数已归一化到 0–1，阈值真正生效）+ 库外行为（拒答/转人工）。
  - **AI 未接管时**：按知识库回答；**库外不调用上游**，按配置转人工或只回拒答文案；命中时消息记录依据条目 id（仅客服可见）。
  - **客服接管后**：AI 只生成 **1–3 条候选推荐**，**绝不自动发送**；客服可自行关闭（总开关）或限定可用库；要求会话已分配给该客服（越权 403）。
- **限额**：访客每分钟/每天消息数、每会话每天 AI 调用数、AI 单次回复字数、超限文案（按访客语言翻译）。频率超限的消息**不落库不处理**并给访客提示；AI 调用达上限**不请求上游**；回复按句末标点截断。

### ⑥ 开放 API 权限范围
- 7 个 scope（应用信息/会话读/会话建/会话关/消息读/消息写/实时订阅），每端点缺范围返回 403 并提示缺哪个范围；`GET /open/v1/me` 返回生效范围。
- 4 套预置（全功能 / 只读订阅 / 仅创建与发消息 / 客服机器人）；`me:read` 始终保留；**空 = 不限制**（旧应用行为不变）。
- 缺范围被拒写审计；管理端 PATCH 已改为指针语义（只发 `enabled` 不会清掉限速/备注/范围）。

### ⑦ 客服策略
- **排队与技能组**：无人在线/并发满时入队，访客可见排队位次；客服上线或并发释放按「优先级 → 入队时间」出队；离线释放且未首响的会话重新入队。
- **SLA**：首响超时与待回复超时（幂等，只告警一次）→ 推送客服 App + 提醒渠道 + 审计；待回复超时后按配置**交回 AI** 或**转其他在线客服**（无候选则入队）。
- **会话超时自动关闭**（可配，0=关闭该功能），复用结束流程让访客可评价。
- **AI / 关键词优先级**四种模式：关键词优先（默认）/ AI 优先 / 仅关键词 / 仅 AI。
- **无人值守兜底**：人类不在线 **且** AI 不可用时，发一次兜底话术（按访客语言翻译）；AI 在接待时不重复发离线话术。
- **黑名单**：访客 / IP / 账号三类，命中建会话或发消息被拒（文案不泄露被拉黑值）并写审计；支持过期时间。
- **接管弹窗 + 只读围观**：新会话与重新入队时推「接管」提示（受客服偏好与全局开关双控）；未接管时 AI 继续接待；客服可**只读围观**（不分配、不计并发、**不标已读**）。
- **提醒渠道**：每个客服最多 3 个 Telegram / Bark / 邮箱渠道，可单独启停、可发测试消息；分配、转接、访客新消息都会派发（失败重试 2 次、不影响主流程）。
- 另有**客服账号级偏好**：自动译入/译出、发送前确认译文、方言模式、AI 推荐发送、知识库推荐、接管弹窗、只读围观。

### ⑧ 安全加固与等保文档
- 后台登录失败锁定（15 分钟 10 次）、2FA 单挑战 5 次上限 + **验证码防重放**、会话落库可**即时撤销**（登出/改密生效）、常量时间签名比较。
- 全局安全响应头（CSP/nosniff/Referrer/X-Frame-Options，HTTPS 下 HSTS）+ Caddy 三站点 HSTS；状态变更接口 Origin 白名单校验。
- CMS 富文本**写入前消毒**（去 script/iframe/事件属性，全量保存路径也覆盖）。
- 生产环境使用示例密钥**拒绝启动**；依赖 `npm audit --omit=dev` 为 0。

### ⑨ 自动翻译与客户画像（你追加的需求）
- **逐条语种识别**（21 语种 + 方言标记 + 「请用 X 语言回答我」整会话生效 + 主语言按占比/平局取最近）。
- **异步翻译流水线**：访客消息→中文（客服端可切「原文」）；客服消息→访客语言（访客端只看到自己的语言，翻译期间显示"正在输入"，失败兜底发原文）。
- **客服 App**：语种标签、翻译状态、原文开关、发送前确认/编辑译文、AI 建议填入输入框（不自动发送）。
- **客户画像**：地理三级（CDN 头 → **本地 GeoLite2 官方 CSV**（零依赖、二分查找、支持 IPv4/IPv6）→ 后台可配第三方 IP 库，按 IP 正/负缓存、超时降级、失败不阻塞会话）；语言/方言/多语混说画像；**国籍只给"推测 + 置信度 + 依据"**（依据键固定为 `ip_cdn|geoip|third_party|language|timezone`，`country` 给中文名并附 `country_code`）；AI 摘要每 N 条异步增量更新（严格 JSON，解析失败不覆盖旧值）；隐私开关（关闭即不采集、不调第三方、接口 404；可只显示脱敏 IP）；控制台画像页（筛选/详情/证据消息/会话深链/重新分析/设置）与 App 会话画像卡。

## 三、未做 / 已知限制（三轮收尾后）

**已解决的原有问题**（本轮起逐条修掉，均有真实测试）：
- ~~本地地理库不支持 mmdb~~ → 已实现**零依赖 MMDB 读取器**（24/28/32 位记录、IPv4/IPv6、指针/字符串/map/array 解码；自造夹具测试 + 用本机真实 mmdb 文件验证 24 位与 28 位库）。`geoip_db_path` 现可指向 `.mmdb` **或** GeoLite2 CSV 目录。
- ~~ai_first/ai_only 只看全局 Key~~ → 已改为**绑定感知**（有可用绑定即视为 AI 可用）。
- ~~Go 与 admin-server 错误体不统一~~ → admin-server 代理层统一归一化为 `{"error":{code,message},"message":...}`（已是对象形状的原样透传）。
- ~~知识库无倒排索引~~ → 已实现**进程内倒排索引**（候选收窄 + 写失效 + TTL + 上限 LRU；1 万条检索 ~110µs，结果与全表 BM25 逐位一致）。
- ~~控制台看不到接管/SLA 提示~~ → 询盘页已加**告警徽标与提示条**（复用原 10s 轮询、隐藏不请求、失败静默）。
- ~~画像 last_path 为空~~ → 已打通：挂件带官网 `visitor_id`（`visitor_ref`）建会话 → 引擎以它为**画像键**并建会话即建画像 → 埋点经 admin-server 转发 → **实测 `last_path` 写入、visits 递增**。
- ~~访问统计依赖同意导致 UV 偏低~~ → 未同意也发**匿名 pageview**，服务端用当日盐 + 截断 IP 派生 UV 键（跨天不可关联），明细仍留 IP 供审计。
- ~~AI 无故障转移/熔断~~ → 已实现多供应商优先级 + 熔断（3 次失败打开 30s、401/403 打开 5 分钟、half-open 单次探测）+ 链感知超时预算；**真实 MiMo 供应商实测 8/8 通过**。

**仍然存在的限制**：
1. **Android/iOS 正式签名与商店发布**：按你的要求不做；`Runner.entitlements` 的 `aps-environment` 上线前需改 `production`。
2. **App 未真机/模拟器验证**（本沙箱禁止 `flutter build` 写 SDK 缓存）。请在你本机执行以下命令验收（每步都给预期结果）：
   ```bash
   cd servicebridge/apps/agent-mobile
   flutter pub get
   flutter analyze                      # 预期：No issues found
   flutter test                         # 预期：全部通过
   flutter run -d <你的设备或模拟器>      # 预期：能登录、收发消息、看到「原文/译文」开关与「AI 建议」按钮
   ```
   人工验收点：① 收到访客西语消息时显示中文译文 + 可切「原文」；② 发送前（若开启「发送前确认译文」）弹译文预览可改词；③ 会话页右上「画像」显示国家/时区/推测国籍与依据；④ 新会话弹「接管」提示，「稍后」后 AI 继续接待；⑤「我的 → 提醒渠道」可配 ≤3 个渠道并「发送测试」。
3. **多节点部署**：知识库索引与熔断状态在**进程内**，跨节点写依赖 TTL（索引 ≤60s）收敛；如需强一致需外置缓存。
4. **画像 `last_path` 只统计"打开过聊天/有意向"的访客**：画像在**建会话时**创建；纯浏览未打开聊天的访客不会建画像（隐私与成本取舍）。
5. **策略告警用全量汇总**（`AllConversations()+QueueList()`，控制台 10s 轮询）：会话量极大时需加索引或增量接口。
6. **本地地理库需自备数据**：GeoLite2 的 `.mmdb` 或 CSV 需你自行下载并挂进容器（MaxMind 许可限制，仓库不分发）。
7. **App 的 AI 建议/画像依赖后端已配置上游**：未配置时按钮会给出明确提示而非静默。
