### ② 系统日志

- 中文展示、等级（info/warning/danger）、分类筛选、关键词与 IP 搜索、详情弹窗（含 UA 全文与明细 JSON）、危险行高亮、CSV 导出、按 IP 过滤。
- **危险识别**：目录穿越、敏感路径探测（.env/.git/wp-admin/phpmyadmin…）、SQLi/XSS 特征、扫描器特征、登录爆破、2FA 爆破、非白名单来源写请求。
- **分层保留**：安全事件与管理员操作默认 **180 天**、访问明细 **30 天**（可配 30–3650 / 1–365，每日自动清理，清理动作写审计）。

### ③ 导航重排
- 6 个根：工作台（数据看板）→ 运营中心（询盘管理/咨询单/客服账号/服务评价/关键词规则/**客服策略**/**排队队列**/**黑名单**/**访客画像**）→ 内容管理 → AI 管理（接待 AI/生图/SEO/翻译 AI/**模型供应商**/**能力绑定**/**知识库**/**限额**）→ 应用管理（App 版本/API 管理）→ 系统（系统日志/审计日志/营业时间与联系方式/推送设置/安全策略式设置/**提醒设置**）。
- 旧地址全部 302/重定向到新路由，旧后台页面已下线。

### ④ AI 统一配置 + 知识库 + 限额
- **多供应商**：可建任意多组 URL+Key，每组可不同模型；**一键获取模型**后模型框变下拉可任选；连通性测试给延迟与模型数；出站主机白名单防 SSRF；密钥 AES-256-GCM 加密、只回掩码。
- **能力绑定**：接待 AI / 翻译 / 语言检测 / AI SEO / AI 生图 各绑一个供应商+模型；未绑定自动回退"系统设置"里的原有上游（升级零影响）。admin-server 侧的**网站翻译、AI SEO、AI 生图也已接入同一套供应商**（60 秒 TTL，保存即失效）。
- **知识库（多库）**：条目 CRUD + 批量导入 + **检索预览**（分数已归一化到 0–1，阈值真正生效）+ 库外行为（拒答/转人工）。
  - **AI 未接管时**：按知识库回答；**库外不调用上游**，按配置转人工或只回拒答文案；命中时消息记录依据条目 id（仅客服可见）。
  - **客服接管后**：AI 只生成 **1–3 条候选推荐**，**绝不自动发送**；客服可自行关闭（总开关）或限定可用库；要求会话已分配给该客服（越权 403）。
- **限额**：访客每分钟/每天消息数、每会话每天 AI 调用数、AI 单次回复字数、超限文案（按访客语言翻译）。频率超限的消息**不落库不处理**并给访客提示；AI 调用达上限**不请求上游**；回复按句末标点截断。

### ⑥ 开放 API 权限范围
- 7 个 scope（应用信息/会话读/会话建/会话关/消息读/消息写/实时订阅），每端点缺范围返回 403 并提示缺哪个范围；`GET /open/v1/me` 返回生效范围。
- 4 套预置（全功能 / 只读订阅 / 仅创建与发消息 / 客服机器人）；`me:read` 始终保留；**空 = 不限制**（旧应用行为不变）。
- 缺范围被拒写审计；管理端 PATCH 已改为指针语义（只发 `enabled` 不会清掉限速/备注/范围）。

### ⑦ 客服策略
- **排队与技能组**：无人在线/并发满时入队，访客可见排队位次；客服上线或并发释放按「优先级 → 入队时间」出队；离线释放且未首响的会话重新入队。
- **SLA**：首响超时与待回复超时（幂等，只告警一次）→ 推送客服 App + 提醒渠道 + 审计；待回复超时后按配置**交回 AI** 或**转其他在线客服**（无候选则入队）。
- **会话超时自动关闭**（可配，0=关闭该功能），复用结束流程让访客可评价。
- **AI / 关键词优先级**四种模式：关键词优先（默认）/ AI 优先 / 仅关键词 / 仅 AI。
- **无人值守兜底**：人类不在线 **且** AI 不可用时，发一次兜底话术（按访客语言翻译）；AI 在接待时不重复发离线话术。
- **黑名单**：访客 / IP / 账号三类，命中建会话或发消息被拒（文案不泄露被拉黑值）并写审计；支持过期时间。
- **接管弹窗 + 只读围观**：新会话与重新入队时推「接管」提示（受客服偏好与全局开关双控）；未接管时 AI 继续接待；客服可**只读围观**（不分配、不计并发、**不标已读**）。
- **提醒渠道**：每个客服最多 3 个 Telegram / Bark / 邮箱渠道，可单独启停、可发测试消息；分配、转接、访客新消息都会派发（失败重试 2 次、不影响主流程）。
- 另有**客服账号级偏好**：自动译入/译出、发送前确认译文、方言模式、AI 推荐发送、知识库推荐、接管弹窗、只读围观。

### ⑨ 自动翻译与客户画像（你追加的需求）
- **逐条语种识别**（21 语种 + 方言标记 + 「请用 X 语言回答我」整会话生效 + 主语言按占比/平局取最近）。

## 三、未做 / 已知限制（明确列出，不含糊）

1. **Android/iOS 正式签名与商店发布**：按你的要求不做。`Runner.entitlements` 的 `aps-environment` 上线前需改 `production`。
2. **本地 GeoLite2 的 mmdb 格式不支持**：本机无法访问 Go 模块代理，不能引入 mmdb 解析库。当前支持 **GeoLite2 CSV**（零依赖）与第三方 IP 库；配置 `.mmdb` 时会给出明确提示，引入解析库后即可支持。
3. **`ai_first` / `ai_only` 的已知退化**：判断"AI 上游是否已配置"时只看全局 `ai_settings`；若只通过「能力绑定」提供 Key（全局 Key 为空），这两种模式会退化为关键词。修复方向：把绑定可用性传入判定。
4. **错误响应体形状不统一**：Go 侧是 `{"error":"code","message":"..."}`，admin-server 侧是 `{"error":{"message":"..."}}`；前端已双形状兼容，但建议后续统一。
5. **知识库检索为内存打分**：中文 bigram + 英文词 + BM25（已归一化），**没有倒排索引**；条目量大（数万级）时需加索引或向量检索。
6. **画像的 AI 摘要**依赖文本上游；未配置上游时只有地理与语言画像（摘要保持上次值）。
7. **画像的 `last_path`（最近访问页面）当前为空**：官网埋点在 admin-server、画像在客服引擎，本波未做跨服务写入；字段与写入口已就绪，埋点接入后即可填充；`visits` 已按建会话计数。
8. **本地地理库支持的是 GeoLite2 官方 CSV**（Blocks + Locations 目录），不是 `.mmdb` 单文件（见第 2 条）。
9. **通知渠道上限 3 个**（按你的要求）；邮件渠道依赖 SMTP，未配置时测试会失败并提示。
10. **`conversation.takeover_request` / `conversation.sla` 为实时事件**：控制台的询盘页目前是轮询刷新（不订阅 WebSocket），因此控制台侧不显示这两类提示，只有客服 App 会弹；如需控制台也提示，需要给询盘页加 WS 或轮询接口。
11. **未做真机/模拟器验证**：沙箱无法运行 `flutter build/test`；App 侧已用 `dart analyze` + 165 条纯 Dart 断言（76 契约 + 89 画像）覆盖解析与文案逻辑，UI 交互未在真机跑过。
12. **4 个浏览器集成测试需要 `/usr/bin/google-chrome`**（本机是 macOS 的 Chrome 路径），因此在 `verify-all` 中记为 SKIP；控制台/前端的 Playwright 冒烟是另用 macOS Chrome 跑的。
13. **官网静态站的访问统计依赖访客同意**：未点同意前不发送埋点，UV 会略低于真实流量（合规取舍）。
