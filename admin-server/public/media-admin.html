Cloudflare R2 接入指南

从创建 Bucket、生成 API Token，到填写后台配置和绑定自定义域名，一步完成真实接入。

打开 Cloudflare 控制台 ↗

接入路径

Cloudflare 控制台→R2 Bucket 与 API Token→本后台存储配置→自定义域名公开素材

四步完成配置

1

创建 R2 Bucket

Cloudflare 控制台 → R2 对象存储 → 创建 Bucket

记录 Bucket 名称；生产与测试环境建议使用不同 Bucket。

2

创建 API Token

R2 → 管理 R2 API Token

授予目标 Bucket 的“对象读和写”权限，保存 Access Key ID 与 Secret Access Key。

3

填写后台配置

素材中心 → 系统设置 → 存储配置

Endpoint 通常为 https://账户ID.r2.cloudflarestorage.com，区域填写 auto。

4

绑定公开域名并验证

Bucket → 设置 → 自定义域

填写 Public Base URL，保存时后台会真实执行 HeadBucket 验证。

后台字段怎么填写

后台字段去哪里找示例注意事项
EndpointR2 API Token 页面 / S3 APIhttps://账户ID.r2.cloudflarestorage.com不要填写 Bucket 名称和查询参数
RegionCloudflare R2 固定值autoMinIO 可用 us-east-1
BucketR2 Bucket 列表site-images必须与 Token 权限一致
Access / Secret Key创建 R2 API Token 后显示只填写后台，不会回显明文Secret 只显示一次，请安全保存
Public Base URLBucket 自定义域https://img.example.com不要以 / 结尾
对象前缀由管理员自定义site-admin已有素材后不可直接更换

预签名直传 CORS

把后台真实域名填入 AllowedOrigins，不要使用通配符。

[
  {
    "AllowedOrigins": ["https://admin.example.com"],
    "AllowedMethods": ["PUT", "GET", "HEAD"],
    "AllowedHeaders": ["Content-Type"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]

配置后验证清单

  1. 保存时显示 Bucket 真实连通
  2. 智能上传能生成 WebP 主图与变体
  3. R2 直传能完成 PUT 与服务端魔数确认
  4. 公开 URL 在官网域名下能直接访问
  5. 后台重启后配置与素材仍然存在
Access Key、Secret Key 和 AI Key 均由 AES-256-GCM 加密保存在 PostgreSQL，页面不返回明文。
